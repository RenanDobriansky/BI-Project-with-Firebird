## Descricao curta para LinkedIn

Desenvolvi uma estrutura de exploracao de dados para um ERP com banco Firebird, focada em inventario tecnico, validacao de relacionamentos e preparacao de fatos e dimensoes para analise comercial no Power BI.

## Descricao media para LinkedIn ou Portfolio

Projeto de BI voltado a um ERP com banco Firebird, com foco na descoberta estruturada do modelo de dados e na preparacao de uma base analitica para Power BI. O trabalho inclui conexao via ODBC com Python, inventario automatizado de tabelas e colunas, classificacao funcional das entidades do banco, validacao de relacionamentos e criacao das primeiras queries para `fVendas`, `fPedidos`, `dClientes` e `dProdutos`.

## Descricao profissional mais forte

Conduzi a etapa inicial de engenharia analitica em um ambiente ERP baseado em Firebird, estruturando a exploracao tecnica do banco e transformando um schema operacional pouco documentado em uma base orientada a BI. O projeto incluiu automacao em Python para conexao via ODBC, inventario de metadados, exportacao de dados, analise de tabelas candidatas por dominio de negocio, levantamento de hipoteses de relacionamento e modelagem inicial de fatos e dimensoes para uso em Power BI.

## Versao em primeira pessoa para portfolio

Neste projeto eu organizei a exploracao de um banco Firebird de ERP com objetivo de montar uma base analitica para Power BI. Criei scripts em Python para conectar via ODBC, gerar inventario do banco, exportar tabelas e consultas, analisar relacionamentos provaveis e estruturar as primeiras queries de `fVendas`, `fPedidos`, `dClientes` e `dProdutos`. O foco principal foi reduzir a dependencia de conhecimento informal do ERP e acelerar a construcao de um modelo estrela voltado ao dashboard comercial.
